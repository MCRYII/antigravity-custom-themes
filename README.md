# 🌈 Antigravity Custom Themes

为 [Google Antigravity](https://antigravity.google/) 打造的**即装即用深浅双模主题套件**（目前暂时只支持 Windows）。下载发行包后双击 `install.bat` 即可完成全部安装；顶栏单胶囊切换器毫秒级免刷新换主题，深浅外观 100% 交由客户端原生 Settings 控制并自动联动主题专属名称，重启自动恢复上次主题选择。

> 📦 本仓库的 GitHub 远端（`MCRYII/antigravity-custom-themes`）为主发行包分发仓：发行包、安装脚本与更新说明均以此处为准；主题开发源码与验收工具保留在本地工作区。

## 🚀 一键安装

1. 从 [**Releases · 最新发行版**](https://github.com/MCRYII/antigravity-custom-themes/releases/latest) 下载 `antigravity-custom-themes-v2.2.zip` 并解压到任意目录
2. **双击 `install.bat`**（需已安装官方 Antigravity；若客户端正在运行，脚本会提示自动关闭）
3. 启动 Antigravity，在 **Settings → Appearance** 中选择深浅外观，点击**顶栏胶囊按钮**切换主题，即刻生效

> 脚本会自动完成：备份原生 `app.asar` → 注入约 20 行主题加载钩子（含完整性校验重算与自检）→ 将主题引擎分发到客户端主题目录。全程无需手动操作。

## 🌙 深色模式（v2 双模架构）

6 款主题均提供完整的 `*-dark.css` 深色变体（暗夜极光 / 深海晴空 / 幽谷碧波 / 熔岩暮色 / 丝绒酒红 / 幻夜幽紫），与浅色母版共享全部 0 ~ 21 节选择器结构、虚拟列表吸顶契约与会话行渐隐遮罩。

- **原生外观总开关**：深浅外观 100% 由 Antigravity 官方 **Settings → Appearance** 控制；主题引擎只读宿主 `dark` / `theme-light` 类名决定注入浅色或深色变体，绝不在外壳增删类名，避免破坏内置设置面板与 Monaco 高亮。
- **动态专属名称联动**：宿主深浅状态变化时，顶栏胶囊标签与下拉菜单中的主题名称自动无刷新切换为深浅专属名（四色极光 ↔ 暗夜极光、蔚蓝晴空 ↔ 深海晴空、碧水青波 ↔ 幽谷碧波、落霞暖橙 ↔ 熔岩暮色、丹霞绯红 ↔ 丝绒酒红、紫罗幽兰 ↔ 幻夜幽紫、官方原版 ↔ 官方原版）。
- **官方原版**：保持 100% 零侵入——`css` / `cssDark` 恒为空字符串，不注入任何覆盖样式，也不改写 `html` / `body` 的原生类名；标题栏由 `readCssVarHex()` 动态采样宿主原生 `--sidebar` / `--foreground`（深色兜底 `#161616` / `#CCCCCC`，浅色兜底 `#FAFAFA` / `#101010`），切换器按实际底色自动取高对比文字，不再出现过曝白字。真正的深浅外观仍由客户端原生设置控制。
- **回溯圆点 / 滑动条**：浅色 6 款与深色 6 款均使用同色系三段渐变（四色极光为蓝→紫→粉红，紫罗幽兰为雾紫→紫罗兰→深紫，其余四款零粉色），当前轮次与悬停态不再统一泛粉，深浅双模质感对称。

深色主题预览可参考 `_review/验收22/preview-*.png`（开发验收截图，未打包进发行包）。

## 🔄 客户端更新后

Antigravity 自动更新会清空主题目录并还原 `app.asar`。更新完成后**重新运行一次 `install.bat`** 即可恢复（脚本幂等，安全无副作用）；安装器会同时检测到客户端版本升级，并把 `app.asar.stock-backup` 自动刷新为当前新版，避免日后卸载误还原旧版。

---

## 🗑 卸载

双击 `uninstall.bat`：先安全关闭 Antigravity 进程，再从备份还原原生 `app.asar` 并删除全部主题文件，重启客户端即恢复原版外观。若客户端已自动升级、当前 `app.asar` 不含主题钩子，脚本会跳过还原以避免降级，仅清理主题文件。

## ❓ 常见问题

**安装后没有效果？**
完全退出 Antigravity（含托盘）后重新启动。主题在页面加载时注入，运行中的旧页面不会自动应用。

**切换主题后重启又变回默认？**
主题通过客户端原生持久化存储（`app_storage.json` 的 `custom-theme-id`）记忆，重启自动恢复。若遇到此问题请确认使用的是最新版 `current.js` 并重新运行 `install.bat`。深浅外观由官方 Settings → Appearance 独立记忆，不属于主题系统。

**可以只恢复原版吗？**
可以，在下拉菜单选择「官方原版」即可；若想彻底移除主题系统，运行 `uninstall.bat`。

## ⚙️ 工作原理（简述）

安装脚本在 `app.asar` 内 `dist/utils.js` 的窗口创建流程中注入一个 `dom-ready` 监听（约 20 行，只读不改任何业务代码），客户端每次加载页面时按 `resources/custom-theme` → `%APPDATA%\Antigravity\custom-theme` 顺序加载 `current.css` 与 `current.js`（运行时目录只需这两个文件；完整 13 套源码 CSS 保留在 WSL 镜像备份中供回填）。主题引擎随后注入样式、挂载顶栏单胶囊主题切换器，并通过 `setTitleBarOverlay` 让原生标题栏与主题（深浅）底色像素级对齐。主题偏好写入客户端自带的键值存储（`app_storage.json`），与缩放级别等原生设置同库，跨重启可靠恢复。
